# OrderManagement.Api Documentation

## Overview

OrderManagement.Api is a RESTful web service designed to manage orders efficiently. The API provides endpoints for retrieving, creating, and deleting orders through a secure, token-based authentication mechanism.

## Base URL

```
https://api.ordermanagement.com
```

## Authentication

All endpoints except `/orders/token` require JWT (JSON Web Token) authentication.

### Obtaining a Token

**Endpoint:** `POST /orders/token`

**Authentication:** Not required

**Parameters:**
| Name | Type | Location | Description |
|------|------|----------|-------------|
| user | string | Query | Username for token generation (default: "demo") |

**Example Request:**
```
POST /orders/token?user=johndoe HTTP/1.1
Host: api.ordermanagement.com
```

**Response (200 OK):**
```json
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
}
```

**Token Validity:** 1 hour from generation time

### Using the Token

Include the token in the `Authorization` header for all authenticated requests:

```
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

## Endpoints

### 1. Retrieve All Orders

**Endpoint:** `GET /orders`

**Authentication:** Required

**Description:** Retrieves a list of all orders in the system.

**Response (200 OK):**
```json
[
  {
    "id": 1,
    "product": "Keyboard",
    "quantity": 1,
    "createdAt": "2024-01-15T10:30:00Z"
  },
  {
    "id": 2,
    "product": "Mouse",
    "quantity": 2,
    "createdAt": "2024-01-15T10:31:00Z"
  }
]
```

**Error Response (401 Unauthorized):**
```json
{
  "error": "Invalid or missing authentication token"
}
```

---

### 2. Retrieve Order by ID

**Endpoint:** `GET /orders/{id}`

**Authentication:** Required

**Description:** Retrieves a specific order by its unique identifier.

**Parameters:**
| Name | Type | Location | Description |
|------|------|----------|-------------|
| id | integer | Path | Unique order identifier |

**Example Request:**
```
GET /orders/1 HTTP/1.1
Host: api.ordermanagement.com
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

**Response (200 OK):**
```json
{
  "id": 1,
  "product": "Keyboard",
  "quantity": 1,
  "createdAt": "2024-01-15T10:30:00Z"
}
```

**Error Response (404 Not Found):**
```json
{
  "error": "Order not found"
}
```

**Error Response (401 Unauthorized):**
```json
{
  "error": "Invalid or missing authentication token"
}
```

---

### 3. Create a New Order

**Endpoint:** `POST /orders`

**Authentication:** Required

**Description:** Creates a new order in the system.

**Request Body:**
```json
{
  "product": "Monitor",
  "quantity": 1
}
```

**Request Body Schema:**
| Field | Type | Required | Description |
|-------|------|----------|-------------|
| product | string | Yes | Name or description of the product |
| quantity | integer | Yes | Quantity of the product ordered |

**Example Request:**
```
POST /orders HTTP/1.1
Host: api.ordermanagement.com
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
Content-Type: application/json

{
  "product": "Monitor",
  "quantity": 1
}
```

**Response (201 Created):**
```json
{
  "id": 3,
  "product": "Monitor",
  "quantity": 1,
  "createdAt": "2024-01-15T10:32:00Z"
}
```

**Error Response (400 Bad Request):**
```json
{
  "error": "Invalid request body"
}
```

**Error Response (401 Unauthorized):**
```json
{
  "error": "Invalid or missing authentication token"
}
```

---

## Data Models

### Order Model

Represents a single order in the system.

```json
{
  "id": 1,
  "product": "Keyboard",
  "quantity": 1,
  "createdAt": "2024-01-15T10:30:00Z"
}
```

**Fields:**
| Field | Type | Description |
|-------|------|-------------|
| id | integer | Unique order identifier (read-only, generated by server) |
| product | string | Product name or description |
| quantity | integer | Number of items ordered |
| createdAt | datetime (ISO 8601) | Order creation timestamp in UTC |

---

## HTTP Status Codes

| Status Code | Description |
|-------------|-------------|
| 200 OK | Request succeeded, response body contains requested data |
| 201 Created | Order successfully created, response body contains created order |
| 204 No Content | Request succeeded, no content to return (e.g., successful deletion) |
| 400 Bad Request | Invalid request parameters or malformed request body |
| 401 Unauthorized | Missing or invalid authentication token |
| 404 Not Found | Requested resource not found |
| 500 Internal Server Error | Server encountered an unexpected error |

---

## Error Handling

All error responses follow a consistent format:

```json
{
  "error": "Error description"
}
```

Ensure your application properly handles HTTP status codes and error responses for robust integration.
